# 模型与思考设置

运行仓库的 **model-settings.cmd**，或在监听管理器点“模型与思考设置”。

设置窗口会暂停**这份项目自己的**聊天任务，避免QQ抢焦点；关闭窗口时，原先运行的监听会恢复，原先停止的仍停止。本地模型服务不停止。另一个目录里的机器人不会被本窗口擅自停止。

## 地址、Key与模型列表

1. 填服务商的API基础地址，例如 `https://api.example.com`、`https://api.example.com/v1`，或完整 `.../chat/completions`。根地址默认补 `/v1`；有自定义前缀时按服务商实际路径填写。
2. 输入API Key。只填Key，不带“Bearer”。本地无认证服务勾选“此接口无需Key”。
3. 点“获取模型列表”。程序向同一API前缀的 `GET /models` 查询。
4. 只有一个模型时自动选中；多个时由你选择，保留列表中仍有效的现有选择，不根据名称或价格猜选。
5. 点“保存设置”，关闭窗口恢复原监听。

列表只是服务商返回的目录，不保证该Key有全部模型的调用权限。如果服务商不提供列表，可手动填写模型ID，并关闭“启动时检查模型列表”。真正调用仍需要一个有效模型ID。

切换接口地址时会清空旧模型选择和本轮输入的Key，新接口默认切回兼容参数，避免沿用Strata预算。

新Key使用Windows DPAPI按当前账户加密，文件在 `.secrets/*.dpapi`，config.json只保存文件路径。Key不写入prompt、公开配置或Git仓库。更换API地址时不会自动把旧Key发给新地址；需要重新填写Key或明确选择无需Key。

已有保存的Key可以留空沿用；新输入框不会直接显示原Key。换电脑、Windows用户或系统重装后，DPAPI文件可能无法解密，需要重新输入。加密文件只在设置Key时产生，不随聊天数量增加。

“使用本地默认”只填写本机8095、deepseek-v4.1-flash、Strata参数、中档自动及原生图片，不自动下载或重启模型；点击保存才应用。

## 思考程度

可选 **关闭思考 / 低 / 中 / 高**。勾选“复杂问题自动提高到高”时，沿用当前基于文字特征的策略；取消勾选则固定使用所选档位，群友说“高档思考”也不会擅自提升。

思考参数不是所有API的统一标准，需选择服务支持的格式：

| 格式 | 实际请求 | 适用 |
| --- | --- | --- |
| 兼容模式 | 不发任何思考参数 | 不支持相关字段的API；界面档位不会控制其实际思考 |
| 通用effort | reasoning_effort | 支持none/low/medium/high对应取值的服务 |
| 本地Strata | reasoning_effort，且非none时加reasoning_budget_tokens | 本项目的本地1017方案 |

Strata的 `reasoning_effort: "none"` 用于关闭思考；不是靠把思考预算填0。其他服务是否支持none，需以其文档为准。界面模型列表通常不会告诉你完整的思考能力，不能保证任意服务都接受这些参数。

## 高级参数

可展开每档的：
- 思考token预算：仅Strata模式发送，关闭档固定为0且不向服务发送预算字段。
- 总生成token上限：Strata中包含思考和正文；其他API以其服务定义为准。
- 超时秒数。
- 上限字段：max_tokens或max_completion_tokens，按服务要求选择。

默认值：

| 档位 | Strata预算 | 生成上限 | 超时 |
| --- | --- | --- | --- |
| 关闭 | 不发送 | 512 | 180秒 |
| 低 | 128 | 768 | 240秒 |
| 中 | 384 | 1152 | 300秒 |
| 高 | 1536 | 2304 | 600秒 |

预算必须小于生成上限。更高预算可能更慢，过大的总请求也可能超出模型上下文；本地方案固定8192上下文，不意味着能任意填大。

## 保存与生效

保存只修改模型接口、认证引用、原生识图和思考/代理/检查选项，保留QQ昵称、人格路径、监听名单与聊天记忆。配置被另一个窗口修改时，会拒绝覆盖，重新打开设置后再保存。

设置窗口打开时会暂停聊天脚本；关闭后重新启动的下一次生成读取新设置。直接手动修改config.json也会在下一次生成读取，已经开始的HTTP请求不会被即时改写。

恢复失败会显示提示，可修正设置后用start.cmd重新启动。模型接口不通时不盲目反复尝试发送QQ消息。

## 仍支持环境变量

不使用窗口存Key时，可继续用 `api_key_env` 指定变量。优先级为：配置了api_key_file时解密该文件；否则读取进程环境变量，Windows后台任务还可回读当前用户Environment注册表项。

```powershell
$key = Read-Host 'API Key'
[Environment]::SetEnvironmentVariable('QQ_BOT_API_KEY', $key, 'User')
Remove-Variable key
```

旧的send_reasoning_parameters仍兼容：没有reasoning_api时，true按Strata格式、false按兼容模式处理。新设置窗口会写明确的reasoning_api字段，优先于旧开关。
