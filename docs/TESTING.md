## 手工验收建议

1. 保持测试会话可见，使用自己的测试对象。
2. 首次启动只记录基线；随后发送一条新文字，核对收发与自身回读。
3. 切到另一测试对象，检查上下文隔离。
4. 发送图片和新提问；确认该会话 captured-images 内出现对应截图，状态中的图片描述来自该条消息。
5. 停止后确认鼠标键盘不再被程序操作；重置仅影响本项目目录。
