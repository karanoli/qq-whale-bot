# 本地数据与公开仓库

代码首次安装后没有监听对象。通过 manage.cmd 添加并核验自己的会话。

## 数据目录

| 位置 | 内容 | 正常运行保留范围 |
| --- | --- | --- |
| conversations/类型_号码/memory.json | 会话文字、图片路径、识图描述 | 最近60条上下文、4000个去重ID、最多200个待处理ID |
| conversations/类型_号码/captured-images/ | 机器人截取的图片 | 每会话最近32张，最长边1024像素、JPEG |
| conversations/类型_号码/vision-cache/ | 本地识图描述 | 每会话最近32份 |
| conversations/类型_号码/direct-cursor.json | 加载消息的对齐游标 | 最近200条 |
| bot-log.jsonl* | 运行事件及回复正文 | 单文件约2MiB轮转，最多3份旧归档 |
| memory-backups/ | reset.cmd 产生的完整记忆备份 | 最近3份 |
| diagnostics/ | 调试输出 | 不自动承诺总大小上限，手动调试产物需自行清理 |

这些是按会话数量增长的数量限制，不是整个目录固定 MB 配额。大段文字和诊断文件也会占空间。

图片截图不是 QQ 缓存原图。无障碍接口不提供原图路径时，程序只保存匹配消息且完整可见的截图，不通过“最新缓存文件”猜测来源。

## 模型接口

默认示例指向本机。聊天文字会发送给你在 config.json 配置的聊天服务；图片会发送给配置的本机识图服务。若自行把聊天接口改为外部服务，相关会话内容也将发往该服务。

API 密钥通过 QQ_BOT_API_KEY / QQ_BOT_VISION_API_KEY 环境变量读取，不填写在示例配置里。日志可能包含聊天正文，不要把运行数据附到公开 Issue。

## Git 排除

.gitignore 排除了真实配置、人格、监听名单、聊天记忆、截图、模型和日志。修改忽略规则或使用 git add -f 时，应自行检查暂存区。仓库里只提供示例配置和示例人格。

重置保留配置和人格，清理旧备份也只处理带本程序 reset-manifest 标记的备份目录。
